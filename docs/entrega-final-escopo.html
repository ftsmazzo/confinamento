Entrega final — o que vamos entregar nesta rodada

Documento de referência da execução. Consolida o pacote de alterações, o pedido da cliente e o alinhamento operacional. Tudo listado em ENTRA será desenvolvido, testado na versão segura, commitado/pushado no GitHub e documentado no manual da topbar.

Versão segura → GitHub → produção Manual: public/assets/manual/ Migrations em storage/migrations/ Dashboard: aguardando
Fechamento: entregar o sistema no lugar da planilha de acompanhamento (dados + previsão + quadro) e a leitura de cocho enxuta (foto + permissão de nota + visão manhã/noite). App do peão, notificação e dashboard por permissão ficam fora desta rodada.
01

Regras de trabalho (invioláveis)

Como cada entrega sobe

Sem exceção, para cada passo concluído:

  • 1 Implementar e testar na versão segura
  • 2 Se houver banco: criar SQL em storage/migrations/ (datado, comentado, aplicável no Adminer)
  • 3 Atualizar o manual da topbar: public/assets/manual/manual-do-sistema.html
  • 4 Commit + push no GitHub (ftsmazzo/confinamento)
  • 5 Só então aplicar migration / pull na versão real
