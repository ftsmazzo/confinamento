P1.1

Hotfix — edição de cadastros (MD5 no MySQL)

Validado na segura 86fa367

Na versão segura, ao editar Curral (e outros CRUDs que usam hash na URL), o MySQL retornava FUNCTION confinamento.MD5 does not exist. O host trata MD5() como função de schema, não como built-in.

O que mudou

  • Model::findByMd5 e findBySha1 resolvem o hash em PHP
  • Não depende mais de MD5() / SHA1() no SQL

Como foi validado

  1. Deploy do fix
  2. Confinamento → Currais → Editar abriu normalmente
  3. Salvou Linha sem erro

Arquivo

  • core app/Core/Model.php
Na versão real: só pull/deploy. Sem migration. Seguro em qualquer MySQL (com ou sem MD5 built-in).
